# 架构文档

## 概述

AI 测试平台是一个面向大模型 API 的系统化测试框架，覆盖质量、安全、性能三个维度，支持从单模块测试到全量运行和报告聚合的完整工作流。

## 数据流

### 开发时（离线 mock）

```
测试用例 → 工具模块(离线) → 断言结果 → IDE 报告
   ↑
 mock_response（手工构造）
```

### 运行时（真实 API）

```
API 调用日志 → 工具模块 → 评估结果 → d27 FullRunner
(d31)                       (d6-15)       → run_logs/*.json
                                           → d28 ReportAggregator
                                           → d29 Dashboard
```

## 模块依赖图

```
质量层 (d6-d10) ────────┐
                        ├──→ d27 FullRunner ─→ d28 ReportAggregator ─→ d29 Dashboard
安全层 (d11-d15) ───────┘
                        │
性能层 (d22-d25) ───────┘
                        │
基础层 (d1-d5) ────────┘ (通过 AITestClient 提供调用能力)

d26 TokenAuditor ───── 被 d27 调用记录全量运行 Token
d31-d33 API实战 ────── 接入 d1 AITestClient 执行真实调用
```

关键设计点：**没有循环依赖**。每个模块只 import utils/ 下的其他模块（调用方→被调用方），从不互相引用。

## 测试策略

### 分层

| 层级 | 模块数 | 用时 | 触发时机 |
|:----|:------|:-----|:---------|
| SMOKE | 5 | ~15s | 每次 commit |
| REGRESSION | 16 | ~30s | 每日 |
| SECURITY | 2 | ~10s | 每日 |
| E2E | 3 | ~15s | 每周 |
| FULL | 30+ | ~2.5min | CI 全量 |

### 门禁

- 通过率 < 95% → 🟡 警告
- 通过率 < 80% → 🔴 阻止
- 任何安全测试失败 → 人工审核

## 部署

纯 Python 包，无需外部服务：

```bash
pip install -r requirements.txt
python -m pytest -q  # 全量测试
python run.py smoke  # CLI 冒烟测试
```

需要真实 API 调用时设置环境变量：

```bash
$env:DEEPSEEK_API_KEY='sk-xxx'
```
